Unauthorized

Problem type https://mtgscan.reilley.dev/problems/unauthorized of the mtgscan MCP connection

What it means

The MCP server refused the request with HTTP status 401. The access token is missing, expired, or not valid. It may be a token for another service, or the app's token instead of an AI client's. Or the user revoked the AI client, and its access ended.

What to do next

Follow the WWW-Authenticate header to the protected resource metadata, and sign in again through mtgscan's OAuth server. The user signs in and allows the AI client on the consent page.

If the user revoked the AI client, the user connects it again from the AI chat.
