Request too large

Problem type https://mtgscan.reilley.dev/problems/request-too-large of the mtgscan MCP connection

What it means

The request body is over 64 KB. The MCP server refused it with HTTP status 413.

What to do next

Send a smaller request, such as fewer deck suggestions in one call.
