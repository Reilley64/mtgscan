Invalid argument

Problem type https://mtgscan.reilley.dev/problems/invalid-argument of the mtgscan MCP connection

What it means

A tool call has an argument that the tool does not take, or an argument that breaks the tool's rules. Examples are an unknown argument, a limit over 50, or a reason shorter than 20 characters. A call to a tool that does not exist gets this problem too.

pointer is a JSON Pointer to the argument at fault, such as /suggestions/1/reason. detail says what is wrong with it. Nothing was saved.

What to do next

Fix the argument that pointer names, as detail says. Then call the tool again.

Do not repeat the same call. It fails the same way.
