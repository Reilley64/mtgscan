Limit exceeded

Problem type https://mtgscan.reilley.dev/problems/limit-exceeded of the mtgscan MCP connection

What it means

The call would pass a limit on deck suggestions. A user gets 30 deck suggestions an hour, and a deck holds 50 open deck suggestions at most. Nothing was saved.

What to do next

For the hourly limit, wait retry_after_seconds, then send the call again.

For a deck with 50 open deck suggestions, withdraw the ones that no longer matter with withdraw_deck_suggestion. Then send fewer.
