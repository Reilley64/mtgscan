Protected copy

Problem type https://mtgscan.reilley.dev/problems/protected-copy of the mtgscan MCP connection

What it means

The incoming copy is a protected copy. The user keeps protected copies out of decks, so a planned swap never holds one. Nothing was saved.

What to do next

Choose another free copy, or tell the user that the only free copy is protected. The user can unprotect it in the app.
