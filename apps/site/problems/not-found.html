Not found

Problem type https://mtgscan.reilley.dev/problems/not-found of the mtgscan MCP connection

What it means

An ID in the call is missing, or it is not the user's. It may be a deck or a copy. pointer names the argument with the ID.

What to do next

Read the ID again with a read tool, such as list_decks or get_deck. Then call again with an ID from that result.

Never guess an ID.
